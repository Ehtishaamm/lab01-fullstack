# HTML, CSS and Bootstrap Lab

## Purpose

This lab demonstrates the basics of HTML, CSS, and Bootstrap. It includes examples of creating grid layouts using CSS Grid and the Bootstrap responsive grid system.

## Files

* `index.html` — Basic HTML page using CSS Grid.
* `style.css` — CSS styles for the HTML page.
* `bootstrap.html` — Bootstrap page demonstrating responsive grid boxes.

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser to view the HTML/CSS example.
4. Open `bootstrap.html` in a web browser to view the Bootstrap example.

The Bootstrap file requires an internet connection because it loads Bootstrap from a CDN.

## Technologies Used

* HTML5
* CSS3
* Bootstrap 5
